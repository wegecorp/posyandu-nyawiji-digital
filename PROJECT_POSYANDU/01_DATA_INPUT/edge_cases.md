# EXCEPTION HANDLING, ATURAN VALIDASI & EDGE CASES (PORTAL NYAWIJI)

## 1. Edge Cases Pelayanan Lapangan & Tata Kelola Data

| Kasus / Kejadian | Kondisi Pemicu | Respon Sistem & Prosedur Operasional (SOP) |
|---|---|---|
| **Balita Mengalami 2T (Weight Faltering)** | Berat badan anak 2x berturut-turut pada sesi bulanan statusnya `TIDAK_NAIK` (atau turun) | 1. Sistem otomatis memberi badge merah peringatan `2T — perlu rujuk`.<br>2. Kader langsung mengarahkan anak ke Meja 4 (Tenaga Kesehatan/Bidan Desa).<br>3. Bidan menerbitkan rujukan ke Puskesmas untuk evaluasi gizi & investigasi medis lanjutan.<br>4. Masuk ke sheet `Daftar Berisiko` pada laporan ekspor. |
| **Koneksi Internet Terputus (Offline / Blank Spot)** | Kader menginput data di dusun terpencil tanpa sinyal internet | 1. Aplikasi beralih ke mode offline (indikator `Tersimpan Offline`).<br>2. Data disimpan dalam antrean lokal (IndexedDB) dengan ID sementara (UUID).<br>3. Kader dilarang logout dari aplikasi.<br>4. Saat perangkat kembali mendeteksi sinyal internet, sistem secara otomatis melakukan auto-sync ke server tanpa duplikasi data. |
| **Konflik Data Penginputan Bersamaan (Race Condition)** | Dua kader membuka dan mengedit data pasien yang sama dari 2 HP berbeda secara simultan | 1. Sistem mendeteksi bentrok versi (version check / last-write-wins).<br>2. Muncul dialog peringatan `Data Bentrok — Muat Ulang`.<br>3. Kader diarahkan memuat ulang halaman untuk menyinkronkan nilai terbaru. SOP menganjurkan 1 posyandu membagi tugas per meja/RT. |
| **Pasien Duplikat / Pendaftaran Ulang** | Kader mendaftarkan nama yang mirip atau tanggal lahir identik dengan pasien lama | 1. Algoritma fuzzy matcher mendeteksi potensi kemiripan data pasien.<br>2. Sistem menampilkan modal peringatan `Pasien Serupa Ditemukan`.<br>3. Kader diarahkan memilih pasien yang sudah ada untuk diedit (ikon pensil), bukan membuat data ganda. |
| **Data Usia Melebihi Batas Standar Z-score (Umur 61–83 Bulan)** | Anak kategori `BALITA_APRAS` berumur di atas 60 bulan (5 tahun 1 bulan s/d 6 tahun 11 bulan) | 1. Data BB dan TB tetap dicatat wajib.<br>2. Kolom Z-score Permenkes 2/2020 dan N/T KMS dikosongkan (status `null`), karena tabel standar Z-score Permenkes 2/2020 hanya berlaku 0–60 bulan.<br>3. Kader tetap memantau tren IMT secara mandiri. |
| **Ibu Hamil dengan Risiko Tinggi (Hipertensi / KEK / Anemia Berat)** | Tekanan darah sistolik ≥140 mmHg, LiLA <23.5 cm, atau HB <11 g/dL | 1. Sistem menandai status `Beresiko` dan menyorot angka indikator.<br>2. Bidan Desa memberikan konseling intensif, PMT Pemulihan Bumil KEK, serta menjadwalkan pemeriksaan dokter di Puskesmas. |
| **Kader Lupa Password / Terkunci** | Kader tidak dapat login ke posyandu | 1. Kader menghubungi Admin Puskesmas pembina.<br>2. Puskesmas menekan tombol `Reset Password` (ikon kunci) pada daftar posyandu binaan.<br>3. Password posyandu kembali ke default, dan kader diarahkan aktivasi password baru pada saat login berikutnya. |
| **Penghapusan Unit Posyandu** | Puskesmas ingin menghapus data posyandu binaan | 1. Sistem memeriksa relasi data pasien dan pengukuran.<br>2. Jika posyandu sudah memiliki data riwayat, sistem menolak penghapusan permanen (`Fail-Safe`).<br>3. Puskesmas hanya diizinkan melakukan `Nonaktifkan Akun` untuk menjaga integritas riwayat kesehatan warga. |
