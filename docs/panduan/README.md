# Gambar Panduan Pengguna

Letakkan tangkapan layar (PNG) di folder ini dengan nama berikut agar tampil di
`PANDUAN-PENGGUNA.md`. Ambil dari aplikasi versi nyata (HP lebih baik).

| Berkas | Isi yang ditangkap | Dipakai di |
|---|---|---|
| `01-login.png` | Halaman login dengan tab Kader Posyandu / Puskesmas / Dinkes | §2 Cara Login |
| `02-daftar-pasien.png` | Beranda kader: kotak cari, filter status, chip usia, kartu pasien | §5.1 Halaman Beranda |
| `03-input-hari-ini.png` | Tab **Input Hari Ini** dengan kolom ukur yang muncul otomatis | §5.1 Mencatat Pengukuran |
| `04-rekap-excel.png` | Modal **Rekap Ringkas** + tombol **Unduh Rekap Excel** | §7 Fitur Bersama |
| `05-kartu-qr.png` | Modal **Kartu QR Pasien** (nama, nomor registrasi, QR) | §5.1 Kartu QR & Pindai |

Catatan:
- Ukuran wajar: lebar 600–900 px, rasio tampilan HP.
- Samarkan (**blur**) nama & nomor registrasi pasien asli sebelum dipakai di dokumen publik.
